# Task: vl_client.js - 国产 VL 调用

## Description

## Acceptance Criteria
- [ ] `decide(task, perception, history)` 返回合法 `{action, params, reason}` JSON

- JSON schema 校验 action ∈ {click, swipe, call_sub, finish, wait} + params
- 配置项：`vl_provider`（qwen/glm）、`vl_api_key`、`vl_model`、`vl_endpoint`
