# Task: executor.js - 执行 VL 决策

## Description
`lib/agent/executor.js`：执行 VL 返回的动作——`click(x,y)` / `swipe(dx,dy)` / `call_sub(sub_name)`。坐标校验（屏幕范围内）+ 执行 + 返回结果反馈给 agent。

## Acceptance Criteria
- [ ] `execute({action:"click", params:{x,y}})` 用 AutoJS click 点击
- [ ] `execute({action:"swipe", params:{...}})` 滑动
- [ ] `execute({action:"call_sub", params:{sub:"..."}})` 路由到 main.js 子流程（task 003）
- [ ] 非法坐标（越界/负数）拒绝 + 返回错误
- [ ] 返回执行结果 `{success, error}`

## Technical Details
- AutoJS `click(x,y)` / `swipe(x1,y1,x2,y2,duration)`（坐标，调研文档验证 ADB tap 准——用 automator.click）
- call_sub 路由表：`{collect_own_energy, stroll}` → task 003 接口
- 坐标校验：0 ≤ x ≤ device_width, 0 ≤ y ≤ device_height
- action 未知 → 报错

- 003（call_sub 接口）
